# Project Bioneer: Pipeline Specification & Local Execution Guide

## Overview
Defines the serverless repository structure and local integration rules for the Bioneer runtime environment.

## Execution Rules
1. **Clipboard Auto-Routing:** Active via `clip_agent.py` to route markdown and python blocks directly to the workspace.
2. **Local Sync:** Maintained via terminal scripts and local repository tracking.
3. **Verification:** Run execution harnesses locally before staging commits.
